# 过程动画与明暗主题样板

启动项目后访问 `/samples`，例如 `http://localhost:3000/samples`。

此入口用于评审动画与主题方案，与原工作台 `/` 分开。默认暗色，右上角可切换浅色。

| 页面 | 三维区中的演示 |
| --- | --- |
| 首页 | 扫描、识别/标定、焊枪预演和文件传输的流程串联 |
| 数据采集 | 虚拟传感器、扫描光幕、点云逐步累积 |
| AI 识别 | 分块/体素示意、语义着色、实例框逐个出现 |
| 坐标标定 | 对应点、连接线、坐标轴旋转对齐 |
| 焊缝管理 | 候选焊缝逐条显现、当前缝和端点高亮 |
| 程序与预演 | 路径描出、铜色头尖沿轨迹移动 |
| 程序下发 | 数据包移向虚拟控制器、示例文件进度 |

左侧按钮开始播放；三维区下方可暂停、重置、拖动进度和选择 0.5/1/1.5/2 倍速。视图支持拖动旋转、滚轮缩放、点大小调整和网格切换。

点云来自内置演示数据，抽取 40,000 个点用于样板。动画用于说明步骤，不是相机实测、模型推理、标定求解或真实 FTP 结果。所有演示指标均不作为设备/算法验收依据。页面不发送采集、识别、FTP 或机器人启动 API 请求。

浏览器回归检查：启动前端后，在 frontend 目录执行 `node scripts/sample-check.cjs`（默认 http://localhost:3018，可通过 APP_URL 指定地址）。检查七个场景、两个主题、播放/暂停/拖动/速度、窗口尺寸，以及没有真实业务 API 调用；截图输出到 `reports/samples/`。可用 CHROMIUM_PATH 指定 Chromium 可执行文件。

## 正式工作台集成

正式页面各三维区域提供“过程演示”，使用相同七套动画。采集、识别、标定、生成程序、下发操作会自动打开对应示意；可暂停、拖动进度、调速，或返回实际点云。演示使用内置样例点云，不读取任务进度、不生成业务结果、不额外调用业务 API；任务状态和成功失败仍由原有接口处理。真实轨迹预演继续使用生成程序中的 TCP 数据。

页头支持明暗主题切换并记住选择；两侧采用 248px / 260px 紧凑布局，中央增加 80px。标定状态卡随内容自适应高度，并用两列显示全部指标。

浏览器回归：`APP_URL=http://localhost:3000 node scripts/formal-presentation-check.cjs`。
